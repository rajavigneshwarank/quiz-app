# Quiz App

A simple and interactive quiz application built using **HTML**, **CSS**, and **JavaScript**. This app allows users to test their knowledge with multiple-choice questions, view their scores, and enjoy an engaging quiz experience.

## Features

- Multiple-choice questions with answers
- Score tracking after completing the quiz
- Simple and responsive design
- Timer functionality (optional, if implemented)
- Easy to set up and use

## Technologies Used

- **HTML** for structuring the quiz app
- **CSS** for styling and layout
- **JavaScript** for interactivity and dynamic behavior
